# Profile maintenance

The profile presents a connected engineering practice, not selected projects.

- Update README.md and README.de.md together. English is the profile default; the language links open the corresponding repository README.
- Keep the catalogue links language-specific and use https://www.jayesh-kakkad.de. Email uses contact@jayesh-kakkad.com.
- Artwork uses one self-contained, theme-neutral SVG per language and component: assets/practice-banner-{en,de}.svg and assets/practice-map-{en,de}.svg. A warm stone panel, deep green text and copper accents keep consistent contrast against any GitHub page background. There is deliberately no theme detection, URL marker or system media query. Native Markdown follows GitHub’s actual palette.
- Images have a 600px intrinsic width and scale down under GitHub's responsive image styling. The vertical map avoids a tiny three-column diagram. Descriptions and a text equivalent remain native Markdown.
- Do not add selected projects, ranking, badge walls, third-party statistics or typing services.
- Future roles must remain future-facing until their start date. GBM is not included pending public-announcement timing.
- Account bio, location, avatar and pins are separate settings and are not changed by this repository update.
- Legacy light/dark practice SVGs, banner.svg, github-metrics.svg, FEATURED_PROJECTS.md and METRICS_SETUP.md are retained for reference, not rendered by the profile. The existing metrics workflow remains unchanged; retiring it is a separate maintenance decision.

## Review checklist

Check both languages, the same artwork on light, dark, dimmed and high-contrast backgrounds, 320px and desktop widths, keyboard-accessible disclosures, alt text, and language/catalogue/contact links. GitHub controls Markdown fonts, page layout and theme; do not embed CSS or JavaScript into the README. Confirm the actual GitHub rendering after publication.
