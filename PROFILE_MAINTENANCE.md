# Profile maintenance

The profile uses a dashboard card design shared with Desk Companion: rounded cards, KPI tiles, chips and the indigo token palette, with light and dark variants that GitHub selects automatically.

- Keep README.md and README.de.md aligned. English is the GitHub profile default.
- Use the .de website and contact@jayesh-kakkad.com email.
- Cards (hero, what I build, toolkit, activity) are SVGs in `assets/cards/`, generated by `scripts/profile-cards.mjs`. Edit card text in the `CONTENT` object there (both languages), never in the SVG files, then run `node scripts/profile-cards.mjs`.
- Embed every card with `<picture>`: a `prefers-color-scheme: dark` source plus a light `<img>` with `width="100%"` and descriptive alt text containing the card's content.
- Text sections (about, teaching, content, contact) stay native Markdown so they remain selectable, translatable and readable on phones.
- The activity card is refreshed twice a day by `.github/workflows/profile-cards.yml` using `METRICS_TOKEN`. It counts real commits via commit search (author + author date across every readable repository), not the profile contribution graph, which undercounts organisation work. It stores aggregate numbers only (`assets/cards/stats.json`), never repository names. The detailed lowlighter metrics remain in a disclosure.
- Keep project discovery comprehensive rather than selecting or ranking projects.
- Do not announce future roles without confirmed public timing.
- Review both languages at desktop and 320px width, light and dark themes, image loading, disclosures and links before publishing.
